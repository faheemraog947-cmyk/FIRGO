# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-09-04

### Added
- Initial project setup with Flutter and Firebase integration
- User authentication system (Login/Signup)
- Passenger functionality:
  - Home dashboard
  - Ride request and booking
  - Ride details and fare calculation
  - Ride history
  - Profile management
- Driver functionality:
  - Home dashboard
  - Available rides listing
  - Earnings tracking
  - Profile management
- Real-time location tracking with Geolocator
- Google Maps integration
- Provider-based state management
- Material Design 3 theming
- Utility functions and extensions
- Comprehensive README and setup documentation

### Project Structure
- Models for User and Ride data
- Providers for Auth, Location, and Ride management
- Multiple screens for different user flows
- Theme configuration
- API endpoints configuration
- Dialog helpers and extensions
